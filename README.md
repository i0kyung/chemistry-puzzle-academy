# 화학 퍼즐 아카데미 (Chemistry Puzzle Academy)

원소 카드를 조합해 화합물을 만들고, 화학 반응을 배우는 교육용 웹 게임입니다.

## 학습 내용
- 원소: 수소(H), 산소(O), 탄소(C), 질소(N), 나트륨(Na), 염소(Cl), 구리(Cu), 은(Ag), 아연(Zn), 마그네슘(Mg)
- 화합물: 물(H₂O), 이산화탄소(CO₂), 암모니아(NH₃), 염화나트륨(NaCl), 산화구리(CuO), 과산화수소(H₂O₂), 산화은(Ag₂O), 탄산수소나트륨(NaHCO₃), 탄산나트륨(Na₂CO₃), 질산은(AgNO₃), 질산구리(Cu(NO₃)₂), 염산(HCl), 염화아연(ZnCl₂), 질산(HNO₃), 질산마그네슘(Mg(NO₃)₂), 염화구리(CuCl₂), 염화마그네슘(MgCl₂)
- 반응
  - Part 1 · 기초 원소 조합
  - Part 2 · 결합 반응
  - Part 3 · 분해 반응
  - Part 4 · 치환 반응
- 카드 한 장은 원자 또는 분자 하나를 뜻하며, 반응 전후 원자 수가 같아지도록(질량 보존) 계수만큼 카드를 고릅니다.
- 조합에 성공하면 카드 조합식, 실제 반응식, 반응 조건, 과학 메모를 함께 보여 줍니다.
- 원소 캐릭터는 시작 화면, 반응에 성공한 순간, 결과창, 도감에만 등장합니다. 퍼즐 보드는 개수를 세기 쉽도록 기호 카드로 유지합니다.
- 모드: 연습 · 일반 · 챌린지(제한 시간)
- 도감: 발견한 원소와 화합물을 브라우저에 기록합니다.
